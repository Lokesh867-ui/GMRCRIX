# GMRCRIX

## Installation
1. Create a new Supabase project.
2. Open `schema.sql` in Supabase SQL Editor and run it once.
3. Create an admin user in Supabase Authentication > Users.
4. Open `js/supabase.js` and paste your Supabase Project URL and Publishable key.
5. Open this folder in VS Code.
6. Run with Live Server. Do NOT use `file:///...`.

## Workflow
Admin login -> Add teams -> Add players -> Create match -> Manage match ->
Select exactly 11 players per team -> Select captain -> Toss -> Start match ->
Select striker/non-striker/bowler -> Score balls -> End innings -> Second innings ->
End match.

## Important
This project is intentionally a fresh replacement. Do not mix these files with an old GMRCRIX project.
